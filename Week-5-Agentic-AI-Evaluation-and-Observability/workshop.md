### Key Learning Outcomes
###Objectives of the workshop:
* Build a **single AI agent** using MCP tools with **role-based access control (RBAC)**.
* Evaluate the agent using **custom evaluators** for tool accuracy, compliance, and response quality.
* Deploy the agent to production using **Amazon Bedrock AgentCore Runtime, Gateway, and Identity**.
* Monitor and troubleshoot agent behavior using **OpenTelemetry (OTEL) traces** and **Amazon CloudWatch metrics**.
* Update **managed datasets** using reviewed evidence collected from production.
* Optimize agent performance using **AgentCore recommendations, A/B testing metrics, and release decisions**.
